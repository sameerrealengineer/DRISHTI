## Layout (PRD §13.2)

- `services/api/app/` — FastAPI. Pure logic lives in modules with no I/O so tests and the back-test run
  without a DB: `risk/engine.py` (math), `risk/pipeline.py` (scenario → inputs → scores + forecast),
  `forecast/nowcast.py`, `reports/triage.py`, `sim/scenario.py`, `geo/static.py`.
  DB/HTTP glue: `models.py`, `seed/loader.py`, `risk/service.py`, `sim/clock.py`, `api/*.py`, `ws/hub.py`.
- `services/api/app/worker/celery_app.py` — Celery worker/beat (same image as the API).
- `apps/web` — React + Vite Command Centre (skeleton: landing + live risk view; full UI is M8).
- `seed/` — reference data. `seed/scenarios/*.json` are generated by `scripts/gen_scenarios.py`.
- `ml/backtest/run.py` — back-test CLI → `reports/backtest_<scenario>.md|json`.
- `packages/design-tokens` — §21.8 tokens → `apps/web/src/theme/tokens.css` (`make tokens`).

## Commands

```bash
make migrate seed-reset   # local DB (PostGIS) schema + seed
make api web              # API on :8000, web on :5173 (proxies /api)
make test lint            # pytest (DB tests skip without PostGIS) + vitest; ruff + eslint + tsc + prettier
make backtest scenarios   # back-test reports; regenerate scenario JSON
```

## Conventions

- Risk math changes go through `DEFAULT_CONFIG` / `risk_config` (versioned), never hard-coded numbers.
- `tests/test_engine.py` re-implements the PRD formula independently; keep both in sync with the PRD.
- Odia strings need native-speaker review (PRD §16.6); mark new ones in `docs/open-questions.md`.
- Never store or log raw phone numbers: `app/security/crypto.py` (`phone_hash`, `encrypt_phone`, `mask_phone`).
- `audit_log` is append-only (DB trigger).
- Everything must work offline in DEMO mode; external calls only in live adapters behind flags.
- Line length 110 (ruff, prettier).

## Known gaps / decisions to revisit

- The reference prototype (`reference/prototype/*`) and original seed files were not in the repo. Seed
  data and scenarios here are approximations; Titli scenario inputs were tuned so landfall scores match the
  M2 DoD numbers. Replace with the prototype's files when available and re-run `make test`.
- v1 forecast holds satellite flood fraction constant, so surge-driven floods (Phailin) are warned late.
  See `reports/backtest_phailin.md`. A surge term is a candidate for v2.
- Docker was not available in the build sandbox: compose/Dockerfiles are written but not yet run.
